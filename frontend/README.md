# FootCall - Frontend

Este directorio contendrá el código fuente del frontend de la aplicación FootCall.
El proyecto está siendo construido con **Next.js**, **React**, y **Tailwind CSS**.

## Estructura del Repositorio (Monorepo)
- `/backend`: Contiene la lógica del servidor (FastAPI), gestionada por el desarrollador backend.
- `/frontend`: Contiene la interfaz de usuario, gestionada por el desarrollador frontend.

## Requisitos Previos
- Node.js (versión LTS recomendada)
- npm o yarn
